# MangaDB code audit, 2026-09-30

Audited commit `6108393` on `t3code/codebase-audit`. Twelve sub-agents reviewed catalog queries, projections, personal tracking, privacy, authorization, moderation, repairs, import orchestration, source adapters, frontend behavior, and the Cloudflare Worker. The parent checked the strongest findings, removed overlaps, and ran the baseline checks. This is an audit of current code, rather than a review of a particular diff.

The first fixes should address stored script injection, private tracking exposed during canonical-record maintenance, deleted personal data restored by Split, and importer identity mistakes. The largest measured efficiency problem is collection batching: 200 new books triggered 40,800 explicit `db.get` calls.

P1 means prioritize before the next relevant rollout or catalog-maintenance operation. P2 means a real correctness, reliability, or scaling issue that should enter the backlog. P3 means a smaller improvement. “Reproduced” means a local fixture exercised the implementation and showed the described behavior. “Traced” means the caller and callee establish the behavior, without an end-to-end reproduction. “Modeled” means a future scaling failure follows from unbounded work; production timing and limits were not exercised.

No application code was changed, deployment functions called, or catalog data written. Temporary reproduction tests were removed. This report is the only intended tracked addition. The Convex guidelines were missing from the worktree, so reviewers read the copy in `/home/ari/Code/Anime/MangaDB/convex/_generated/ai/guidelines.md`.

## Domain decision requiring reconsideration

`convex/lib/matching.ts:308` treats disjoint known ISBN sets in the same format as proof of different Series. A reproduction showed an existing Volume 1 ISBN rejects incoming evidence containing only another physical ISBN of the same work. That can happen with incomplete backlists, upcoming-only feeds, or different printings.

This behavior is explicitly described in `CONTEXT.md`, so it is a documented policy tradeoff rather than a demonstrated implementation departure. Consider returning `unknown` when the sources cover different Volume positions or publication packaging, while retaining strong creator and overlapping-book checks. Changing this guard should include the existing wrong-work matching regressions.
